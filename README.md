### 🚀 About Me

I am a passionate **Game Systems Architect** and **Full-Stack Developer** focused on engineering immersive virtual worlds, high-performance distributed backends, and pixel-perfect interactive user interfaces.

- 🎮 **Game Systems & Mechanics:** Architecting low-latency game loops, synchronized server-authoritative state, and custom gameplay modules for FiveM (Qbox / vRP / FXServer).
- 💎 **Modern NUI & Web Frontend:** Crafting ultra-responsive, liquid-glass in-game interfaces and modern web applications with **React 19, TypeScript, TailwindCSS, Vite & CEF**.
- ⚡ **High-Concurrency Backends:** Developing resilient microservices, secure authentication systems, and WebSocket architectures using **Node.js, Fastify, PostgreSQL & Redis**.
- 🛡️ **Zero-Trust Security & Optimization:** Engineering robust player authorization pipelines, CEF GPU rendering optimizations, and defensive anti-exploit standards.
