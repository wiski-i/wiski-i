## Repositories

### [Crosshair Studio](https://github.com/wiski-i/Starlit-Crosshair)

A native Windows crosshair editor and overlay built with C# and .NET Framework. You can draw and adjust a reticle in a live preview, check its contrast against different backgrounds, and save your designs as profiles.

- **Per-game profiles** switch to the saved design when the chosen game window comes into focus.
- **Profile packs** let you export custom reticles and preview a pack before importing it.
- **Monitor selection and pixel calibration** let you place the overlay precisely on your setup.

[Build and run on Windows](https://github.com/wiski-i/Starlit-Crosshair#build-and-run)

## [Starlit Roleplay](https://starlit-roleplay.com)

Starlit Roleplay is a FiveM multiplayer project I develop with a team. My work spans server-side gameplay, in-game interfaces, and backend services that connect the game to the wider community.

## What I work with

- **Gameplay and networking** · Lua, FiveM, synchronized player state, and server-side game logic.
- **Web and in-game interfaces** · TypeScript, React, and animation for interfaces that run inside the game.
- **Backend services** · Node.js, Fastify, PostgreSQL, and Redis for APIs, authentication, and persistent data.
- **Desktop tooling** · C# and .NET Framework for native Windows apps, plus Python for scripting and tooling.
